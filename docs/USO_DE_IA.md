# Registro de apoio de IA — preencher antes da entrega

Ferramenta: ChatGPT (assistência à criação de protótipo de referência e documentação).

Prompt relevante do usuário: "crie todos os modulos em um zip".

Uso: estrutura e código demonstrativo de API Node.js/SQLite, interface HTML/CSS/JS, exemplos de testes e documentos de apoio.

Atenção: a atividade acadêmica pode proibir submissão de código gerado por IA. Verifique o roteiro, não entregue este protótipo como autoria própria e registre com precisão todas as interações efetivamente utilizadas.
